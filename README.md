# TTZ-TUBE

Custom Smart TV streaming interface and playback enhancement module.

## Highlights
- **Midnight Obsidian & Cyan Focus UI:** High-contrast dark theme with crisp leaf-level cyan selection rings and progress scrubber.
- **Seamless Sponsor & Promo Auto-Skip:** SponsorBlock integration plus watch-only caption guard.
- **Clean Subscription Rail:** Deduplicated, alphabetically sorted channel list and smooth 60fps scrolling.
